# prebuilt-libebml

Android libebml 1.4.5 outputs for Nova, generated by
`native/libebml-android-builder`. Supports armeabi-v7a, arm64-v8a, x86 and x86_64
at API 23 with `c++_static` and position-independent code.

- `include/`: public upstream headers and generated export declarations.
- `lib/<ABI>/`: static archive and relocatable CMake package exports.
- `build-info/<ABI>.json`: pinned source, toolchain and output checksums.
- `LICENSE`, `LICENSE.libebml`, `NOTICE`: Nova and upstream attribution.

The libmatroska bundle additionally contains `libnova_matroska.so` in each ABI
directory and both LGPL texts under `share/matroska/` for APK packaging. Its
shared library links libmatroska and libebml statically with 16 KiB ELF alignment.

Regenerate from the workspace with:

```sh
make native_build_native/libebml-android-builder
```

Keep all ABI libraries and their headers/metadata together. Do not include
host binaries or builder caches. Nova support files are Apache-2.0; bundled
upstream code retains LGPL-2.1-or-later. Source URLs and hashes are in `NOTICE`
and the builder. This is a separate repository on `main`; publish it alongside
the matching builder before syncing the updated AVP manifest remotely.
